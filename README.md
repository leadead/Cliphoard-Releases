# Cliphoard

macOS 剪贴板历史工具：自动记录复制的文字、图片和文件，按 ⌘⇧V 在屏幕底部调出历史，点选或用 ← → 选中后粘贴到当前 App。

## 功能

- **剪贴板历史**：记录文字、图片和文件，默认保存 3 天
- **固定常用条目**：固定的条目不过期，可以起名称、修改文字内容
- **以纯文本粘贴**：默认开启，可以在设置中关闭
- **iCloud 同步**：历史和设置在同一 Apple 账号的多台 Mac 之间同步

界面支持简体中文、English、日本語、Tiếng Việt。

## 下载与安装

系统要求：macOS 26 及以上，Apple Silicon。

1. 下载 [Cliphoard.dmg](https://github.com/leadead/Cliphoard-Releases/releases/latest/download/Cliphoard.dmg)（[所有版本](https://github.com/leadead/Cliphoard-Releases/releases)）
2. 打开 DMG，把 Cliphoard 拖到「应用程序」文件夹
3. 从「应用程序」打开 Cliphoard，按引导授予剪贴板访问和辅助功能权限；之后可以推出 DMG

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在菜单栏图标的菜单中点「检查更新…」。

## 隐私

Cliphoard 不采集、不上传任何数据。历史只保存在本机和你自己的 iCloud 私有数据库中，带敏感标记的内容（如密码管理器）不记录。
